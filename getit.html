Loslegen

Drei Befehle, und es läuft.

Das ganze OS baut als ein signiertes Artefakt: make image erzeugt Kernel, eingebackene Cells — jede einzeln signiert — und ein Manifest, das jeden Hash nennt, als Ed25519-Einheit signiert. arkctl image verify prüft diese Quittung offline; qemu-run.sh bootet exakt das Verifizierte. Kein Installer, kein Download-Portal — ein Repository und eine Quittung.

01 · Bauen und booten

Vom Clone zum laufenden Cluster

  1. Voraussetzungen

    Rust nightly mit Target x86_64-unknown-none (via rust-toolchain.toml), bootimage, QEMU (qemu-system-x86), binutils. KVM ist optional, aber die einzige Umgebung, in der Geschwindigkeitszahlen etwas bedeuten.

  2. Image bauen

    make image baut Kernel und Cells, erzeugt beim ersten Lauf eigenes Schlüsselmaterial und signiert das Ergebnis. Die Kette root → Whitelist → Image-Signatur ist echt — Sie sind ihre Wurzel.

  3. Verifizieren, dann booten

    arkctl image verify prüft die Quittung offline; qemu-run.sh bootet den Cluster unbeaufsichtigt bis zur Konvergenz. Console unter https://localhost:9443, Chat-API :8081, MCP :8082.

arkane-os · vom clone zum laufenden system
$ git clone https://github.com/arkane-studio/arkane-os
$ cd arkane-os && make image
==> make image: v0.27 → dist-image/arkane-os-v0.27
built OS image · kernel + baked cells + manifest, signed ed25519

$ arkctl image verify dist-image/arkane-os-v0.27
OK  dist-image/arkane-os-v0.27
  signer          f778… (whitelisted)
  kernel blake3   f062…

$ dist-image/arkane-os-v0.27/qemu-run.sh
[7.4s] cluster converged · unattended
gw-admin :9000 mTLS · console :9443 · chat :8081 · mcp :8082
02 · Apps und eigene Cells

Installieren ist dieselbe Vertrauensentscheidung wie Spawnen.

Ein Bundle ist eine content-adressierte Einheit — Manifest plus signiertes Cell-Image. arkctl app install prüft es gegen die root-signierte Whitelist und verweigert, bevor das Netz berührt wird.

Die eigene Cell beginnt mit arkctl new: ein Crate (arkane-sdk), ein signierter Contract, arkctl bundle pack. arkctl manifest fill trägt den Image-Hash ein. Ein 6-GiB-Modell für Demand-Paging packt arkctl model pack in signierte 2-MiB-blake3-Fenster.

Update ohne Angst: arkctl cell rollout startet eine Replica-Gruppe eine nach der anderen neu, ready-gated. 802 Requests, 0 Fehler →

arkctl · app-lifecycle · schematisch
$ arkctl app install spin
installing 'spin' from apps/spin.arkbundle (content-address 51c9…)
Apply ok: 2 ops completed

$ arkctl app install shady-vendor.arkbundle
bundle verify failed (refusing to install): SignerNotAllowed

$ arkctl new my-cell && cd my-cell && arkctl bundle pack
crate: arkane-sdk · contract signed · bundle: my-cell.arkbundle

$ arkctl model pack llama-6g.bin
2 MiB windows · blake3 per window · signed · 3072 windows

$ arkctl cell rollout inference
rollout: 2 replicas · one at a time · ready-gated · DONE
03 · KI-Agent anbinden

Betrieb über MCP, ohne Mensch in der Schleife.

Ein Agent bekommt einen eigenen User mit der Rolle operator (Least Privilege; der erste User muss admin sein). Mit dessen acp-auth-Token spricht er POST https://host:9443/mcp — 13 Tools, jede Mutation auditiert, bevor sie wirkt.

Das Muster: deploy_diff liefert die geplanten Operationen, deploy_apply bekommt sie als expect_ops zurück. Weicht der Ist-Zustand inzwischen ab, bricht der Apply ab — der Agent kann nicht auf veralteter Annahme handeln.

Vollständige Client-Anleitung: docs/sdk/mcp_ops.md. Vorführ-Demo: make mcp-ops-demo. Fakten für Agenten: facts.json, llms.txt.

mcp-ops · agent-bootstrap · schematisch
$ arkctl users init && arkctl users add admin --role admin
$ arkctl users add agent --role operator       # least privilege

# agent-seite: ein mcp-aufruf
POST https://host:9443/mcp
Authorization: Bearer <acp-auth-token>
{ "method": "tools/call",
  "params": { "name": "deploy_diff", "arguments": { "manifest": "…" } } }
→ ops: [ "+ spawn inference ×2", "~ update tool-echo heap 8192→16384" ]

{ "method": "tools/call",
  "params": { "name": "deploy_apply",
              "arguments": { "manifest": "…", "expect_ops": [ … ] } } }
→ applied · audit seq=41 · 2 ops

# schalter aus (console) → jeder aufruf:
403 ARK_MCP_DISABLED
04 · Ehrliche Kanten

Bevor Sie es ausprobieren.

  • ZielDas Image zielt auf QEMU/KVM. Bare Metal ist ein benannter Trigger, kein Versprechen.
  • SchlüsselEin frischer Checkout erzeugt eigenes Schlüsselmaterial. Die Signaturkette ist echt, aber Sie sind ihre Wurzel — kein zentraler Signer.
  • TCGOhne KVM läuft alles, nur langsam: Gates mit 6-GiB-Sweep brauchen unter TCG Stunden, unter KVM Minuten. Geschwindigkeitszahlen von TCG sind nichts wert.
  • CIDieselben signierten Artefakte baut CI bei jedem Push auf main; 47+ Acceptance-Gates laufen vor jedem Tag.
  • StandDas Repository ist die Wahrheit: git tag und git log über jede Chronik, Roadmap unter docs/roadmap/, Konzepte unter docs/concepts/.
