Arkane OS — its own platform, not another Linux

    
An operating system
built from isolated cells.

    
Apps run as cells directly on an exokernel —
    no Linux syscall stack in the path, capability enforcement in the kernel
    itself. Faster and structurally safer for native workloads. And availability
    is design principle number one: updating an app never takes it down.
